Lab 02: Data Types

What you'll learn today:

How variables and data types (int, float, str) work together
How to call functions and methods, and the difference between them
How to clean up and convert text data with string methods
How to work with lists and NumPy arrays for bulk computation
Learning Goals
Area	Concept
Data Types	Variables store data; type determines what you can do with it
Strings	Text data — characters between quotes
Functions	Reusable operations: print(name), abs(-5)
Methods	Functions bound to a value: name.upper()
Arrays	Collections of values for bulk computation
