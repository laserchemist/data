🦉 Submission Instructions

Two files to save alongside your Submit Lab click — every lab, every week.

Clicking Submit Lab records your score, but it doesn't hand in your actual notebook. Every lab in this course also asks you to download two copies of your work as backups that can be checked against your recorded score: the raw .ipynb file, and an HTML export uploaded to the matching Canvas assignment.

📥 1. Download your notebook as .ipynb

In JupyterLab (what you're using on the Temple hub):

  1. Save your work first — Ctrl+S (Windows/Linux) or Cmd+S (Mac), or File → Save Notebook.
  2. In the left-hand File Browser, right-click your notebook's filename.
  3. Choose Download.

If the file browser panel isn't open, click the folder icon in the far-left sidebar to open it first.

Alternative: File menu → Save Notebook, then File menu → Download. Both routes produce the same .ipynb file — pick whichever is visible in your JupyterLab layout.

🖨️ 2. Export an HTML copy for Canvas

Canvas assignments generally don't accept .ipynb uploads directly, so you'll also export a self-contained HTML version that opens in any browser:

  1. With your notebook open and saved, go to the File menu.
  2. Choose Save and Export Notebook As… → HTML.
  3. Your browser will download a .html file with the same name as your notebook.
  4. Go to the matching assignment in Canvas and upload that .html file.
If your JupyterLab version shows File → Download as → HTML instead, that's the same feature under an older menu name — use whichever one appears.

✅ Checklist, every lab

  • Ran every cell top to bottom (Run → Run All Cells) so outputs are up to date
  • Clicked Submit Lab in the notebook
  • Downloaded the .ipynb file
  • Exported and uploaded the HTML file to Canvas
